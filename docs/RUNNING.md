# 运行应用指南

## 开发环境

### 启动开发服务器

```bash
pnpm dev
```

这会：
1. 启动 Vite 开发服务器（端口 5173）
2. 启动 Electron 应用
3. 启用热模块替换（HMR）
4. 自动打开开发者工具

## 生产环境预览

### 构建应用

```bash
pnpm build
```

### 预览生产构建

```bash
pnpm start
```

**重要说明**：
- `pnpm start` 使用 `file://` 协议加载构建后的文件
- 不需要开发服务器运行
- 用于测试生产构建

## 常见问题

### 错误：Not allowed to load local resource

**原因**：在生产环境预览模式下，路由配置尝试连接开发服务器（端口 5173），但服务器未运行。

**解决方案**：
1. 确保先运行 `pnpm build` 构建应用
2. 然后运行 `pnpm start` 预览
3. 路由配置会自动检测环境并使用 `file://` 协议

### 更新按钮问题

如果更新按钮无法点击或模态框不显示：

1. **检查控制台日志**：
   - 打开开发者工具（F12）
   - 查找 `[UpdateButton]` 和 `[UpdateModal]` 日志

2. **确认组件导入**：
   - UpdateButton 现在直接导入 UpdateModal（不再使用动态导入）
   - 确保没有循环依赖错误

3. **检查环境**：
   - 开发环境：按钮显示为"更新(调试)"
   - 生产环境：按钮显示为"点击更新版本"

## 开发 vs 生产

| 特性 | 开发环境 (pnpm dev) | 生产预览 (pnpm start) |
|------|---------------------|----------------------|
| 热更新 | ✅ | ❌ |
| 开发者工具 | ✅ 自动打开 | ❌ 需手动打开 |
| 文件加载 | http://localhost:5173 | file:// |
| 构建速度 | 快（按需编译） | 慢（完整构建） |
| 调试 | 完整源码 | 编译后代码 |
